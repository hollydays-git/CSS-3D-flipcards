# CSS-3D-clickable-flip-cards: Book Flip Cards

A small collection of interactive 3D cards showcasing four experimental novels: House of Leaves, S., The Raw Shark Texts, and Bats of the Republic.

**[View the live website](https://hollydays-git.github.io/CSS-3D-flipcards/)**

## Features

- Click a book cover to reveal its description and details.
- Click Return to flip the card back.
- Raised text creates depth during the 3D animation.
- Hover effects highlight covers and controls.
- Links lead to book information, author biographies, and Amazon listings.
- Cards wrap onto additional rows when the window narrows.

## Technologies

HTML, SCSS, CSS Grid, Flexbox, and CSS 3D transforms. The flip interaction uses checkboxes and labels without JavaScript.

## Run locally

Open `index.html` in a browser or use VS Code Live Server.

To edit the styling, modify `styles.scss` and compile it into `styles.css` using Live Sass Compiler. The compiled CSS is included in the repository.

## Project background

Created for the Limelight internship assignment, based on the [provided flip-card example](https://github.com/Lime-Light-TechLead/CSS-3D-clickable-flip-cards). The book selection, card layout, and visual design were adapted for this project.

Displayed prices are demonstration values and are not synchronized with Amazon. Mobile layout improvements are planned.
